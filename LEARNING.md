# Learning

Constraint matching alone permits unrelated packages; rooted closure prevents
orphan selections. Compatible cycles can work, while a version constraint in a
cycle can reject every supplied choice. Empty roots select nothing, even if an
unused compatible cycle exists in the catalog.

Candidate choices change the dependency graph. A failed A2 requirement on C
must disappear when switching to A1/B1. Fresh trial state prevents invented
contradictions. Budget interruption differs from finite exhaustive no-solution:
finding a witness still leaves an all-solutions answer incomplete.

Oracle formatters can have bugs. A shared mutable construction input changed
core-cap after its expected report was assembled. Preserve original evidence;
restore the intended input openly without product-generated expectations.

Mutations must hit intended assertions without crashes. Inverted bounds have
both sides false so OR still fails; equal-open has one pass and exposes AND->OR.
Descending build order happened to match one declaration order; ascending literal
tiebreak exposes that stable-order control. Original source stays unchanged.

Sandbox OS temporary paths failed; workspace-scoped fixtures fixed the harness.
Native floats reject in preflight before budget schema checks. Output-size seams
include JSON limits and LF. Full reports verify ordering/provenance/null fields.

Optional exercise: reason about all vectors after changing a synthetic dependency;
explain why the first16preview cannot certify all remaining trials independently.
